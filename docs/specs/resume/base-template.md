  Top of Resume Page
  - Page title: Resume / CV
  - Download/print control

  1. Contact Information
  This section is a labeled personal/contact block.

  Structure:
  - Section heading: Contact Information
  - Full Name: [person's full name]
  - Email: [email address]
  - Phone: [phone number]
  - Site: [main website URL]
  - Social: [list of social profiles presented in sequence]
    - [social network name] -> [profile URL]
    - [social network name] -> [profile URL]
    - [social network name] -> [profile URL]
  - Location: [city, state/region, country]

  2. Professional Summary
  This section contains a heading and one main summary paragraph.

  Structure:
  - Section heading: [summary section title, usually "Professional Summary"]
  - Summary text: [single descriptive paragraph summarizing profile, experience, strengths, and areas of expertise]

  3. Work Experience
  This section is a list of experience entries.
  Each entry is organized around one sentence that combines job title and company, followed by the employment period, then references to roles and projects.

  Structure for each experience entry:
  - Main line: [job title] at [company name]
  - Company anchor/reference: #[company-id]
  - Employment period: [date-of-employment]
  - Roles:
    - #[role-id]
    - #[role-id]
    - #[role-id]
  - Projects:
    - #[project-id]
    - #[project-id]
    - #[project-id]

  Example structural form:
  - Senior Software Engineer at Example Company  #example-company
  - 08/2024 - Present
  - Roles: #software-engineer, #tech-lead
  - Projects: #internal-platform, #automation-suite

  4. Projects
  This section is a list of project entries sorted by year.
  Each project has an identifier, a short display title, a fuller title, a summary, bullet points, optional links, and referenced skills.

  Structure for each project entry:
  - Project display title: [short-title]
  - Project anchor/reference: #[project-id]
  - Full title: [title]
  - Summary: [short explanatory paragraph]
  - Bullet points:
    - [bullet]
    - [bullet]
    - [bullet]
  - Links:
    - [link label] -> [URL]
    - [link label] -> [URL]
  - Skills:
    - #[skill-id]
    - #[skill-id]
    - #[skill-id]

  5. Roles
  This section defines the role references used in Work Experience.
  Each role entry has a title and a list of responsibilities/descriptions.

  Structure for each role entry:
  - Role title: [role title]
  - Role anchor/reference: #[role-id]
  - Description items:
    - [responsibility]
    - [responsibility]
    - [responsibility]

  Example structural form:
  - Software Engineer  #software-engineer
  - Responsibilities:
    - Develop and test software applications.
    - Maintain existing systems.
    - Collaborate with cross-functional teams.

  6. Skills
  - Skill label: [human-readable skill name]
  - Experience time: [calculated years since "since-year"]
  - Skill anchor/reference: #[skill-id]

  Example structural form:
  - Python
  - 13 years
  - #python

  7. Education
  This section is not a generic list in the current template.
  It is organized into three fixed academic blocks:
  - Doctorate
  - Master's
  - Bachelor's

  7.1 Doctorate
  Structure:
  - Title: [degree title]
  - University: [university name]
  - University link: [URL]
  - Location: [place]
  - Attended: [period]
  - Notes: [additional note]
  - Areas of Study: [comma-separated academic areas]

  7.2 Master's
  Structure:
  - Title: [degree title]
  - University: [university name]
  - University link: [URL]
  - Location: [place]
  - Graduated: [year]
  - Dissertation Title: [title]
  - Areas of Study: [comma-separated academic areas]

  7.3 Bachelor's
  Structure:
  - Title: [degree title]
  - University: [university name]
  - University link: [URL]
  - Location: [place]
  - Graduated: [year]
  - Monograph Title: [title]
  - Areas of Study: [comma-separated academic areas]

  8. Publications
  This section is a list of publication entries.
  Each one is concise and contains title, optional access link, and area.

  Structure for each publication entry:
  - Title: [publication title shown in the resume]
  - Access link: [URL] (optional)
  - Area: [field or subject area]

  9. Teachings / Lectures
  This section is a list of teaching, lecture, or training entries.

  Structure for each teaching/lecture entry:
  - Title: [name of lecture, training, course, or presentation]
  - Description: [short explanation of what was taught or presented]

  10. Languages
  This section is a simple list of language entries.

  Structure for each language entry:
  - Language: [language name]
  - Proficiency: [level]

  Example structural form:
  - Portuguese: native
  - English: advanced

  11. Companies
  This section defines the company references used earlier in Work Experience.
  Each company entry contains identification, links, location, and tags.

  Structure for each company entry:
  - Short name: [short display name]
  - Company links:
    - [icon/link reference] -> [URL]
    - [icon/link reference] -> [URL]
  - Full company name: [complete company/institution name]
  - Location: [place]
  - Tags:
    - [tag]
    - [tag]
    - [tag]

  Example structural form:
  - ExampleCo
  - Links: company site, LinkedIn, GitHub
  - Full name: Example Company Incorporated
  - Location: New York, NY, US
  - Tags: technology, cloud, software
